## Entry

> Sorry I ate your boarding pass. You feed me the cheapest paper, swear at me, then ask for colour — honestly, we’re even.

A single-line apology note from an office printer to the people who keep jamming it, feeding it cheap paper and swearing at it — 120 characters.

## How it works

`main.py` (Python standard library only) writes the entry line to `/output/entry.txt`, with assertions that it is exactly one line of 1–120 characters, with no leading/trailing whitespace and no control characters, and sets the output file mode to 644.

Run it with:

```sh
python3 main.py
```
